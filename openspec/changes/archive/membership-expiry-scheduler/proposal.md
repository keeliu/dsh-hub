# 会员到期后台定时处理

## Why

当前会员到期检查（`checkMembershipExpiry`）在每次 API 请求时同步执行，扫描全表查找到期会员。随着用户量增长：
- 每次请求都扫描 `users` 表，增加不必要的数据库负载
- 到期处理（停止实例、发邮件）是阻塞操作，拖慢请求响应
- 无法保证到期时刻的及时性（只有用户发起请求时才检查）

需要增加后台定时任务，将到期检查与请求链路解耦。

## What Changes

1. 新增 `scheduler.ts` 定时任务模块（基于 `setInterval`，零依赖）
2. 每小时扫描一次到期会员，批量执行：停止实例 → 更新会员状态 → 发送通知邮件
3. 到期前 3 天发送提醒邮件
4. 保留请求时的同步检查作为兜底（防止定时任务异常）

## Impact

- **新增文件**：`src/scheduler.ts`
- **修改文件**：`src/index.ts`（启动/停止调度器）、`src/membership.ts`（提取批量处理函数）
- **不影响**：会员创建、付费激活、管理员手动设置
