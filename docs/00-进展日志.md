## M1 完成总结（2026-08-22）

- 实现：`dsh-hub/src/{db,pwd,users,sessions,api,index}.ts`，零依赖（Node 24 内置 `node:sqlite` WAL + `crypto.scrypt`）。
- 功能：首启向导（无用户→`/api/auth/setup` 建管理员，此后 403）；注册开关默认 closed、管理员可开；首位注册（未 setup）自动 root 兜底；登录/登出；会话 cookie（HttpOnly + SameSite=Lax + 滑动 7 天）；写操作 CSRF（双重提交，Bearer 免）；角色三级 user/admin/root（越权 403）；登录限速（5 次错锁 15 分钟，进程内）；API token 双轨（Bearer，可吊销）；审计骨架；管理员用户 CRUD/封禁/重置密码/配额；settings。
- 测试：`scripts/m1-smoke.sh` 24/24 PASS + `scripts/m1-first-root.sh` PASS。
- **计划偏差（已记录）**：密码哈希用 Node 内置 **scrypt**（N=2^15, r=8, p=1）而非计划的 argon2id——保持运行时零依赖；「换 argon2id」移入 M5 加固项。昵称→URL slug 因无中文音译，中文昵称回退 `u-<random8>`（计划 docstring 承诺的音译待 M4 UI 后可配）。
