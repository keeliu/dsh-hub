## M1 完成总结（2026-08-22）

- 实现：`dsh-hub/src/{db,pwd,users,sessions,api,index}.ts`，零依赖（Node 24 内置 `node:sqlite` WAL + `crypto.scrypt`）。
- 功能：首启向导（无用户→`/api/auth/setup` 建管理员，此后 403）；注册开关默认 closed、管理员可开；首位注册（未 setup）自动 root 兜底；登录/登出；会话 cookie（HttpOnly + SameSite=Lax + 滑动 7 天）；写操作 CSRF（双重提交，Bearer 免）；角色三级 user/admin/root（越权 403）；登录限速（5 次错锁 15 分钟，进程内）；API token 双轨（Bearer，可吊销）；审计骨架；管理员用户 CRUD/封禁/重置密码/配额；settings。
- 测试：`scripts/m1-smoke.sh` 24/24 PASS + `scripts/m1-first-root.sh` PASS。
- **计划偏差（已记录）**：密码哈希用 Node 内置 **scrypt**（N=2^15, r=8, p=1）而非计划的 argon2id——保持运行时零依赖；「换 argon2id」移入 M5 加固项。昵称→URL slug 因无中文音译，中文昵称回退 `u-<random8>`（计划 docstring 承诺的音译待 M4 UI 后可配）。

## M2.1 完成总结（2026-08-22，安全修复 + 结构去重）

**背景**：对 M1/M2 代码做了全量安全审查（两个独立子代理交叉验证 + 攻击剧本实证），
修复全部高危/中危缺陷，并拆分散落代码、对齐文档承诺。基线：M1 24/24 + M2 29/29 全绿
（修复前复跑），修复后复跑仍全绿 + 新增 `scripts/security-regression.sh` 安全回归全过。

**高危修复（含实证）**：
- 封禁生效：统一鉴权入口强制 `status=active`；封禁 = 停全部实例 + 吊销会话与 API token；
  管理员不可改自己的 status/role（防 root 自杀/自解封，原缺陷已实测复现）；
- `harness_version` 白名单（RCE 已实证）：仅允许显式 semver（`0.1.1-rc.2`），拒绝
  `file:`/`github:`/`git+`/`latest` 等任意 npm spec；API 层 + supervisor 双层校验；
  `default_harness_version` 设置生效（原设置了不生效），新增 `allowed_harness_versions` 精确白名单；
- `canManage` 收紧：admin 只能管 user（对齐计划 §3.6「root 管管理员」）；
- spawn `error` 事件处理（原 ENOENT 会 uncaughtException 拖垮整个 hub）；
- 运行期 exit 事件同步 DB（实例崩溃后不再永久 running/占配额）；
- 进程身份校验（/proc cmdline 含 dsh + --port，防 pid 复用误杀）；
- stop/start/delete 并发互斥：API 层 per-instance 409 + 锁文件持有者 token。

**中危修复**：配额检查与写入事务化（BEGIN IMMEDIATE，并发建实例不再超配）；登录时间
侧信道（用户不存在也跑 dummy scrypt）；登录限速键 = IP+昵称且锁过期归零（防永久锁号 DoS）；
密码重置/封禁吊销 token；进程组停止等组清空（不再只等组长）+ 端口释放确认；子进程早退
立即中止探活（不再白等 180s）；fd 泄漏（锁/日志 fd 及时关闭）；web.out.log 超 16MiB 轮转
（落实文档「轮转式」承诺）+ tailLog 尾部读取（不再整文件读入）；DELETE 与 start 竞态防护。

**结构去重（去屎山）**：新拆 `src/{config,http,auth,settings,version}.ts`（配置集中、
HTTP 基础设施、统一鉴权+限速、设置读写、版本白名单）；路由声明式 `{auth, csrf}` 选项，
handler 不再各自重复「鉴权+CSRF」三连；`getUser` 等数据访问归位 users.ts；withTx 事务
辅助；BANNER 版本号从 package.json 读取；死字段（auto_restart/mem_max_mb/cpu_quota_pct、
route_mode/credential_mode）标注 M5/M3 预留。

**测试与文档**：`scripts/m1-smoke.sh` 改为自带启动 hub（原需手动起服务，易误跑成 0/24）；
`m2-smoke.sh` 无效断言（pidfile 恒真）修正；新增 `scripts/security-regression.sh`（攻击
剧本：封禁链路/版本注入/并发配额/并发 setup/崩溃同步/并发操作/畸形编码/空昵称）。

**行为变化（兼容性说明）**：API 响应格式不变，新增错误码 `invalid_harness_version`、
`harness_version_not_allowed`、`instance_busy`、`invalid_nickname`；登出（logout）现在
需要 CSRF 头（与其余写操作一致）；空昵称注册/建号返回 400（原随机回退导致无法再登录）。
