# 变更提案：免费体验与双价格展示

## 为什么做

1. **免费体验需求**：1天体验会员价格为0元，当前流程会生成支付二维码，但实际无需支付。需要优化流程，当金额为0时跳过支付环节，直接创建实例。

2. **双价格展示**：当前会员购买页面只显示一个价格，无法体现优惠力度。需要同时展示原价和优惠价，原价划线展示，优惠价放大标红，增强营销效果。

3. **价格管理完善**：管理后台价格管理需要同时支持原价和优惠价的设置。

## 做什么

### 1. 零金额支付优化
- 当会员价格为0时，跳过虎皮椒支付流程
- 直接创建订单（状态为 paid）并激活会员
- 自动创建 DSH 实例
- 前端显示"正在开通..."而非支付二维码

### 2. 双价格展示
- 数据库 `membership_prices` 表新增 `original_price` 字段
- 会员购买页面同时展示原价和优惠价
- 原价使用删除线样式（灰色）
- 优惠价放大并标红
- 默认价格调整：
  - 1天体验：原价 9.9，优惠价 0
  - 月会员：原价 29.9，优惠价 19.9
  - 年会员：原价 299，优惠价 199.0

### 3. 管理后台价格管理
- 价格管理表单新增"原价"输入框
- 同时保存原价和优惠价

## 影响范围

### 数据库
- `membership_prices` 表新增 `original_price` 字段
- 数据库 Migration v6

### 后端
- `membership.ts`：`getMembershipPrice` 返回原价和优惠价
- `membership.ts`：`createOrder` 处理零金额订单
- `api.ts`：`/api/membership/plans` 返回双价格
- `api.ts`：`/admin/api/membership-prices` 支持设置双价格

### 前端
- `views/user.ts`：会员购买页面展示双价格
- `views/admin.ts`：价格管理表单新增原价输入框

### 支付流程
- 零金额订单跳过虎皮椒支付
- 直接激活会员并创建实例
