# 功能规范：免费体验与双价格展示

## 场景 1：零金额订单创建

**Given** 用户已登录且无有效会员
**And** 1天体验会员的优惠价为 0 元
**When** 用户点击"免费体验"按钮
**Then** 系统创建订单，状态直接为 `paid`
**And** 系统立即激活会员
**And** 系统自动创建 DSH 实例
**And** 前端显示"正在开通..."
**And** 1秒后跳转到成功页面

## 场景 2：零金额订单 API 响应

**Given** 1天体验会员的优惠价为 0 元
**When** 前端调用 `POST /api/payment/create` 并传入 `{"type": "trial"}`
**Then** API 返回 `{ "freeTrial": true, "orderId": "xxx" }`
**And** 不返回 `qrcodeUrl` 字段

## 场景 3：会员购买页面展示双价格

**Given** 数据库中设置了会员价格
**When** 用户访问会员购买页面
**Then** 每个套餐卡片显示两个价格
**And** 原价显示为删除线样式（灰色）
**And** 优惠价显示为放大红色字体

## 场景 4：会员购买页面价格示例

**Given** 价格配置如下：
  - 1天体验：原价 9.9元，优惠价 0元
  - 月会员：原价 29.9元，优惠价 19.9元
  - 年会员：原价 299元，优惠价 199元
**When** 用户访问会员购买页面
**Then** 1天体验卡片显示：~~¥9.9~~ **¥0**
**And** 月会员卡片显示：~~¥29.9~~ **¥19.9**
**And** 年会员卡片显示：~~¥299~~ **¥199**

## 场景 5：API 返回双价格

**Given** 数据库中设置了会员价格
**When** 前端调用 `GET /api/membership/plans`
**Then** API 返回每个套餐的 `price`（优惠价）和 `originalPrice`（原价）

## 场景 6：管理后台价格管理

**Given** 管理员已登录
**When** 管理员访问价格管理页面
**Then** 每个套餐显示两个输入框：原价和优惠价
**And** 价格以元为单位显示（如 9.90）

## 场景 7：管理后台设置双价格

**Given** 管理员在价格管理页面
**When** 管理员填写原价 29.9 和优惠价 19.9 并保存
**Then** 系统同时保存原价和优惠价
**And** 会员购买页面显示更新后的价格

## 场景 8：零金额订单不触发支付网关

**Given** 1天体验会员的优惠价为 0 元
**When** 用户购买1天体验会员
**Then** 系统不调用虎皮椒支付 API
**And** 不生成支付二维码

## 场景 9：数据库迁移

**Given** 数据库版本为 v5
**When** 系统启动
**Then** 自动执行 Migration v6
**And** `membership_prices` 表新增 `original_price` 字段
**And** 默认价格设置为：
  - trial: original_price = 990, price = 0
  - monthly: original_price = 2990, price = 1990
  - yearly: original_price = 29900, price = 19900

## 场景 10：优惠价大于原价时的处理

**Given** 管理员设置优惠价大于原价
**When** 管理员保存价格
**Then** 系统允许保存（不强制校验）
**And** 页面正常展示两个价格
