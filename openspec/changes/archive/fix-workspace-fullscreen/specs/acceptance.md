# 验收规范：DSH 实例页面整屏显示

## 场景 1：DSH 页面完整显示

**Given** 用户已登录且有运行中的 DSH 实例
**When** 用户访问 `/workspace` 页面
**Then** 页面顶部显示 Hub 导航栏（60px 高度）
**And** DSH 页面在导航栏下方完整显示
**And** 页面底部内容不被截断
**And** 页面可以正常滚动

## 场景 2：DSH 页面内容滚动

**Given** DSH 页面内容超过视口高度
**When** 用户滚动页面
**Then** 只有 DSH 页面内容区域滚动
**And** Hub 导航栏保持固定在顶部

## 场景 3：不同分辨率下正常显示

**Given** 用户在不同分辨率的屏幕上访问（1920x1080、1366x768、2560x1440 等）
**When** 用户访问 `/workspace` 页面
**Then** DSH 页面都能完整显示
**And** 底部内容不被截断
**And** 页面高度自适应视口

## 场景 4：DSH 页面内嵌功能正常

**Given** DSH 页面包含可滚动内容（如长对话、代码块等）
**When** 用户在 DSH 页面内滚动
**Then** DSH 页面内部滚动正常
**And** 不影响 Hub 导航栏
**And** 不出现双重滚动条

## 场景 5：其他页面不受影响

**Given** 用户访问 Hub 层其他页面（/instances、/profile、/admin 等）
**When** 用户浏览这些页面
**Then** 这些页面的布局和滚动行为不受影响
**And** 仍然使用原有的 layout 渲染逻辑
