# 验收规范：修复实例管理页面导航栏重复

## 场景 1：实例管理页面正常渲染

**Given** 用户已登录且拥有至少一个实例
**When** 用户访问 `/instances` 页面
**Then** 页面只显示一个顶部导航栏
**And** 导航栏包含"乌鸦 work"品牌、用户头像、用户昵称
**And** 页面内容正常显示实例列表

## 场景 2：无实例时页面正常渲染

**Given** 用户已登录但没有实例
**When** 用户访问 `/instances` 页面
**Then** 页面只显示一个顶部导航栏
**And** 页面显示空状态提示"暂无实例"

## 场景 3：其他页面不受影响

**Given** 用户已登录
**When** 用户访问以下页面：
- `/instances/new`（新建实例）
- `/instances/:id`（实例详情）
- `/profile`（个人中心）
- `/membership`（会员购买）
**Then** 这些页面都只显示一个顶部导航栏
**And** 页面渲染正常，无重复内容

## 场景 4：管理员页面不受影响

**Given** 管理员用户已登录
**When** 管理员访问 `/admin/instances`（实例总览）页面
**Then** 页面只显示一个顶部导航栏
**And** 导航栏显示"系统管理"链接（而非"智能体"）
**And** 页面显示侧边栏导航和实例列表

## 场景 5：代码一致性

**Given** 检查所有页面路由处理逻辑
**When** 审查 `pages.ts` 中的页面渲染代码
**Then** 所有 `renderXxxPage` 函数的调用方式一致
**And** 没有多余的 `layout` 包裹
