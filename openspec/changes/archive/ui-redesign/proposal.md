# 变更提案：UI 视觉风格重设计

## Why

当前 DSH Hub 的 UI 样式较为简陋，缺乏统一的设计语言。需要根据最新设计稿统一所有页面的视觉风格，提升产品专业度和用户体验。

## What Changes

### 设计特征提取

从设计稿中提取以下关键视觉规范：

**配色方案**
- 主色（Primary）：`#0066cc`（蓝色）
- 背景色：`#ffffff`（白色）/ `#f5f5f5`（浅灰输入框）
- 文字色：`#1a1a1a`（标题）/ `#666666`（副标题）/ `#999999`（占位符）
- 成功色：`#52c41a`（绿色标签）
- 危险色：`#ff4d4f`（红色文字/按钮）
- 边框色：`#e8e8e8`

**组件样式**
- 圆角：卡片 `12px`，按钮 `24px`（全圆角），输入框 `24px`
- 阴影：卡片 `0 2px 8px rgba(0,0,0,0.08)`
- 输入框：浅灰背景 `#f5f5f5`，无边框，圆角
- 按钮：主按钮蓝色背景白色文字，次要按钮灰色背景
- 标签：小圆角 `4px`，彩色背景

**布局结构**
- 登录/注册/忘记密码：居中卡片，最大宽度 `400px`
- 管理后台：顶部黑色导航栏 + 左侧白色侧边栏 + 主内容区
- 会员购买：三栏卡片布局

### 受影响页面

1. **认证页面**（`views/auth.ts`）
   - 登录页
   - 注册页
   - 忘记密码页
   - 重置密码页

2. **用户页面**（`views/user.ts`）
   - 实例列表页
   - 会员购买页
   - 个人中心页

3. **管理页面**（`views/admin.ts`）
   - 仪表盘
   - 用户管理页
   - 实例总览
   - 审计日志
   - 全局设置
   - 会员管理页

4. **布局组件**（`views/layout.ts`）
   - 顶部导航栏
   - 侧边栏（管理后台）
   - 公共 CSS 样式

## Impact

- **用户可见**：所有页面视觉风格统一为新的设计语言
- **向后兼容**：仅样式变更，不影响功能逻辑
- **风险**：低风险，纯 CSS 调整
