# 提案：管理后台用户账号字段显示 + 管理员登录修复

## 状态
Proposed

## 动机

### 问题 1：用户管理界面缺少账号字段
管理后台用户管理界面的列表中只显示用户昵称（nickname），没有显示用户账号（username）字段。管理员无法直接看到用户的登录账号，不便于用户管理。

### 问题 2：管理员无法进入管理后台
管理员退出登录后：
1. 访问 `/setup` 被重定向到 `/login`（正确行为）
2. 使用管理员账号登录后，无法进入管理后台
3. 没有"进入管理后台"的入口或跳转

## 目标

1. 在管理后台用户管理列表中增加"账号"（username）字段
2. 管理员登录后能够正常进入管理后台
3. 根据用户角色自动跳转到对应页面（管理员→管理后台，普通用户→实例列表）

## 变更范围

### 前端页面
- `views/admin.ts`: 用户管理列表增加账号字段
- `pages.ts`: 登录成功后根据角色跳转

### 后端逻辑
- 无需修改（API 已返回 username 字段）

## 影响

- 管理员可以更清楚地管理用户
- 管理员登录体验改善
- 无破坏性变更

## 验收标准

1. 管理后台用户管理列表显示"账号"字段
2. 管理员登录后自动跳转到管理后台
3. 普通用户登录后跳转到实例列表
4. 类型检查通过
